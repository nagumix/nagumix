# Contributing to NaguMIX

NaguMIX welcomes contributions that can be shared under the project's existing
license boundaries.

By intentionally submitting a contribution for inclusion, you represent that
you have the authority to submit it and grant the permissions required by the
applicable project license. Application code, tests, scripts, configuration,
build files, and reusable code examples are submitted under
`AGPL-3.0-or-later`. Original documentation prose is submitted under
`CC-BY-SA-4.0` unless its file says otherwise. Do not submit third-party material
without recording its source, license, required notices, and any modifications.

Contributors retain copyright in their contributions. Names and contributions
are preserved through Git history and applicable credit/notice records. A pull
request does not assign copyright and does not authorize unrelated relicensing.
Changing the license of retained contributions later requires the necessary
permission from their rights holders.

No contributor license agreement, copyright assignment, or sign-off line is
required by this policy. If you cannot grant the applicable permissions, mark
the submission clearly before it is reviewed or incorporated.

Branding changes require separate approval because the NaguMIX name, logos,
icons, and other branding artwork are outside the code and documentation grants.
